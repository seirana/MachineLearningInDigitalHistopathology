# Archived research scripts

This directory contains the original exploratory Python scripts from the 2018–2019 digital-histopathology project.

They are retained for research history and traceability, but they are **not** the maintained software interface.

For current code, use:

```text
src/histopathology_pipeline/
```

The archived scripts may contain machine-specific paths, older library APIs, import-time execution, and assumptions tied to the original computing environment. Historical NumPy state files are grouped under `legacy/data/`.

See [../LEGACY.md](../LEGACY.md) for the modernization boundary and [../MIGRATION.md](../MIGRATION.md) for the mapping toward the maintained architecture.
